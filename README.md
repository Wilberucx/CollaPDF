Collapdf es un organizador de imágenes que permite agrupar imágenes y poder imprimirlas en un pdf, permitiendo elegir entre 3 tamaños predeterminados:
Small, Medium, Large; las cuales pueden ser cada uno como se considere.
Este proyecto fue desarrollado solo para solucionar un problema el tedioso y repetitivo trabajo de

1. Copiar la imagen de internet.
2. Pegarla en Word, docs de Google, etc.
3. Ajustar manualmente cada imagen para que se ajuste de forma uniforme.
4. Colocarme el nombre correspondiente debajo de cada imagen

Con Collapdf:

1. Descargar las imágenes nombrarlas en el momento.
2. Elegir las imagenes dentro de Collapdf
3. Exportarlas.
